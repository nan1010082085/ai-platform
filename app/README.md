# AI 智能助手

> 用自然语言对话，快速生成表单和流程图

## 它能做什么？

**对话式创建** — 告诉 AI 你想要什么，它帮你生成：
- 表单 Schema（审批单、数据录入、调查问卷...）
- BPMN 流程图（请假、报销、采购审批...）
- 数据看板和图表

**智能理解** — 支持多种输入方式：
- 文字描述需求
- 上传设计稿图片，AI 自动识别生成对应表单
- 上传 PDF、Word、Excel 文档，提取结构化信息
- @ 引用知识库中的已有 Schema

**实时预览** — AI 生成的内容立即可视化渲染，支持版本历史和对比

## 快速开始

### 1. 启动服务

```bash
# 启动后端服务
cd server && pnpm dev

# 启动 AI 前端（新终端）
cd ai/app && pnpm dev
```

### 2. 打开浏览器

访问 `http://localhost:5300`

### 3. 开始对话

- 点击「新建对话」
- 选择 Agent 类型（自动/表单/流程）
- 输入你的需求，例如：
  - "创建一个请假申请表单，包含请假类型、开始时间、结束时间、请假原因"
  - "设计一个报销审批流程，金额超过 5000 需要总经理审批"
  - "把这个设计稿图片转换成表单"

## 核心功能

### 多 Agent 对话

| Agent | 擅长 |
|-------|------|
| Auto | 自动识别意图，智能路由 |
| Editor | 表单设计，生成 Schema JSON |
| Flow | 流程设计，生成 BPMN 流程图 |

### 丰富的交互

- **Markdown 渲染** — 代码高亮、表格、列表
- **流式输出** — 实时看到 AI 思考和生成过程
- **多模态输入** — 图片、PDF、Word、TXT
- **@ 提及** — 引用知识库中的已有 Schema
- **任务链** — 复杂任务自动拆解，进度可视化

### 对话管理

- 创建、切换、删除对话
- 搜索历史对话
- 按 Agent 类型筛选
- 对话标题自动生成/手动编辑

### Schema 预览

- AI 生成的 Schema 实时渲染
- 版本历史浏览
- JSON Diff 对比
- 一键回滚到任意版本

### RAG 知识库

- 语义搜索相关 Schema
- 自动注入上下文，提高生成质量
- 支持文档上传和自动索引


## 常见问题

**Q: 支持哪些 LLM？**
A: 默认使用 DeepSeek，也支持 OpenAI、Anthropic 等兼容 API。

**Q: 生成的内容可以修改吗？**
A: 可以，在预览界面直接编辑，或继续对话让 AI 调整。

**Q: 如何提高生成质量？**
A: 上传相关文档到知识库，AI 会参考已有设计。
